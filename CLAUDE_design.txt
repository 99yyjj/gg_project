#Products (상품 기본)

GET /products → 상품 목록 조회
GET /products/count → 상품 수 조회
GET /products/{product_no} → 상품 단건 조회
POST /products → 상품 생성
PUT /products/{product_no} → 상품 수정
DELETE /products/{product_no} → 상품 삭제

#Products images (대표 이미지)

POST /products/{product_no}/images → 이미지 업로드
POST /products/images → 상품 번호 없이 이미지 업로드
DELETE /products/{product_no}/images → 이미지 삭제
